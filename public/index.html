URLSHOT网页截图 API连接中

URL → PNG

一个网址，一张截图。

支持 GET、POST、DELETE、PATCH，透传业务 Header 和 Body。默认 PC 视图，自动截取整页高度。

GET / POST / DELETE / PATCHhttps://shot.l2cl.link/{domain}?$device=pc&$width=1440

调用示例

# PC，默认 1440px 宽，整页高度
curl 'https://shot.l2cl.link/example.com' -o shot.png

# 手机，默认 390px 宽，整页高度
curl 'https://shot.l2cl.link/example.com?$device=phone' -o phone.png

# 平板，自定义宽高
curl 'https://shot.l2cl.link/example.com?$device=pad&$width=820&$height=1180' -o pad.png

参数

参数默认与行为
$devicepc / phone / pad，默认 pc；使用对应 UA 和触控设置
$width可选；PC 1440、手机 390、平板 820px；传入值优先
$height可选；省略时截取 100% 内容高度，传入时截取指定高度
$force可选；$force=1 强制重新渲染并更新缓存，省略时优先读取缓存

$width：100–2560；$height：100–4096。整页上限 30000px 高、3000 万像素。返回 PNG；相同参数持久缓存 30 天；缓存盘上限 2GB，空间不足时淘汰最久未使用的缓存。

普通 GET 截图支持 Cloudflare 边缘缓存；携带鉴权、Cookie、自定义业务 Header、Body 或使用其他 Method 时，使用隔离的源站缓存。$force=1 跳过缓存并在成功后更新全局图片版本。边缘命中日志异步回写 SQLite，不等待回源统计。

Body 上限 1MB；Host、Content-Length 和代理 Header 自动处理；鉴权 Header 仅传给目标同源网站。显式传入 $device 时使用设备 UA，否则透传传入的 User-Agent（缺省为 PC UA）。鉴权、Body 和 Method 均参与缓存隔离。日志仅记录统计字段及 Method。

支持域名后跟路径，如 /example.com/docs。默认访问 HTTPS；也支持 /https://example.com 或编码后的完整 URL。只有以 $ 开头的参数控制截图，其它参数均传给目标网站，例如 /baidu.com?wd=test&$device=phone。仅支持公开网站。
